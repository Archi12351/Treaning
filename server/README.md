# AI-собеседник: серверный прокси (Cloudflare Worker)

Маленький сервер, который прячет ключ Anthropic API от браузера. Приложение
(GitHub Pages) обращается к этому Worker'у, а Worker — уже к api.anthropic.com
со своим секретным ключом.

## Зачем это нужно

Без бэкенда каждый пользователь приложения должен был вставлять свой личный
ключ Anthropic в Настройках (BYOK). С этим прокси — ключ один, платите за все
разговоры пользователей вы (как владелец ключа), пользователям ничего вводить
не нужно.

**Важно:** ключ, который вы туда положите, должен быть настоящим, привязанным
к вашему платному аккаунту Anthropic — такого ключа, который можно было бы
использовать бесплатно или анонимно, не существует.

## Установка (один раз, ~5 минут)

1. Зарегистрируйтесь на [cloudflare.com](https://dash.cloudflare.com/sign-up)
   (бесплатно, только email).
2. Установите инструмент командной строки Wrangler:
   ```bash
   npm install -g wrangler
   wrangler login
   ```
3. Из папки `server/` этого репозитория задеплойте Worker:
   ```bash
   cd server
   wrangler deploy
   ```
   Wrangler выведет адрес вида `https://deutsch-ai-proxy.<ваш-логин>.workers.dev`
   — это и есть URL бэкенда.
4. Добавьте секретный ключ (получить на
   [console.anthropic.com](https://console.anthropic.com) → API Keys):
   ```bash
   wrangler secret put ANTHROPIC_API_KEY
   ```
   Вставьте ключ, когда попросит, и нажмите Enter.
5. Пришлите мне URL из шага 3 — я подключу его во фронтенд, и приложение
   будет использовать бэкенд вместо запроса ключа у пользователя.

## Ограничения защиты от злоупотреблений

- CORS ограничен доменом `archi12351.github.io` — обычный браузер не даст
  постороннему сайту дёргать этот Worker из JS.
- Это **не защита от прямых запросов** (curl/скрипт может подделать заголовок
  Origin). Если увидите резкий рост расходов в консоли Anthropic —
  добавьте правило Rate Limiting в дашборде Cloudflare для этого маршрута,
  или временно отключите Worker (`wrangler delete`).
- `max_tokens` ограничен 400 на ответ, история разговора — 40 сообщений, что
  ограничивает стоимость одного запроса.

## Локальная проверка

```bash
cd server
wrangler dev
```
