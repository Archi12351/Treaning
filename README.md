# Deutsch A1–C2

Мобильное веб-приложение (PWA) для изучения немецкого языка от A1 до C2.
Работает прямо в браузере телефона и устанавливается на домашний экран одной кнопкой —
отдельно ничего скачивать не нужно.

## Возможности

- **Тест на уровень при первом входе** — 30 вопросов (A1 → C2), которые определяют
  текущий уровень; тест можно пройти позже или повторить в любой момент.
- **Индивидуальная программа** — на главном экране приложение само подбирает, какие
  темы грамматики, лексики и разговорные сценарии проходить дальше, отталкиваясь
  от текущего уровня и того, что уже пройдено.
- **Учебный план** — полная пошаговая программа по уровням (A1 → C2): для каждого
  уровня — что сначала прочитать в учебнике, какие темы грамматики пройти
  упражнениями, какие слова выучить и каким диалогом закрепить. Уровни выше
  текущего+1 показаны закрытыми, чтобы не хвататься сразу за всё подряд.
- **Учебник A1–C2** — полный грамматический справочник по параграфам (20 глав, от
  алфавита и произношения до косвенной речи и номинализации), с правилами,
  исключениями, таблицами склонений/спряжений и произношением примеров.
- **Лексика** — 220+ слов и выражений от A1 до C1 по 20 темам (от «Приветствие» и
  «Семья» до «Экономика» и «Наука»), карточки со spaced repetition (интервальное
  повторение по алгоритму SM‑2), произношение через синтез речи.
- **Грамматика (тренажёр)** — 18 тем от A1 до C1 (артикли и падежи, времена,
  модальные глаголы, Konjunktiv II, пассив, придаточные предложения, косвенная речь,
  номинализация и др.) с объяснением, примерами и упражнениями. У каждой темы —
  пул из 15 упражнений, сессия каждый раз случайно берёт 10 из них в новом порядке,
  так что задания не повторяются один в один от захода к заходу. При ошибке
  показывается не только правильный ответ, но и объяснение, почему он верный.
- **Тесты** — смешанные проверочные тесты по лексике и грамматике со случайным набором
  вопросов и итоговым баллом.
- **Экспресс-режим** — сессия на 5 минут с таймером: быстрые карточки + грамматика,
  чтобы заниматься даже при нехватке времени.
- **Разговорная практика по сценариям** — 16 диалогов от A1 до C2 (от «Знакомство» и
  «В булочной» на старте до деловых переговоров и общественной дискуссии на C2),
  каждый со своим собеседником-аватаром. Диалоги открываются по мере роста уровня —
  на один уровень выше текущего доступны сразу, более высокие показаны закрытыми.
  Бот озвучивает реплики (Text‑to‑Speech), а вы отвечаете голосом — приложение
  распознаёт речь (Speech‑to‑Text) и сверяет её с ожидаемым ответом.
- **AI-собеседник (голос)** — свободный разговор на любую тему с настоящей
  языковой моделью, которая подстраивается под ваш уровень, отвечает голосом
  и мягко поправляет ошибки. Два провайдера на выбор в Настройках: **Claude**
  (через общий серверный прокси, см. `server/README.md`, либо, пока он не
  настроен, через собственный ключ Anthropic) и **Gemini** (всегда через
  собственный бесплатный ключ Google, см. ниже).
- **Аватары** — свой аватар (эмодзи) выбирается в Настройках и виден рядом с
  вашими репликами в диалогах и в AI-чате; у каждого собеседника по сценарию —
  свой аватар (официант, врач, HR и т.д.).
- **Профиль/прогресс** — уровень, XP, серия дней подряд, история тестов на уровень,
  статистика по лексике и грамматике.

Голосовые функции используют встроенные в браузер Web Speech API (`speechSynthesis` /
`SpeechRecognition`). Лучше всего работают в Chrome на Android; в Safari на iOS
поддерживается озвучивание, распознавание речи может быть ограничено.

### AI-собеседник: бэкенд или свой API-ключ

По умолчанию (пока не настроен серверный прокси) приложение работает полностью
в браузере, и каждый пользователь вставляет свой ключ Anthropic в Настройках —
он хранится только в localStorage этого браузера.

Чтобы убрать эту необходимость для всех пользователей, разверните маленький
серверный прокси (Cloudflare Worker), который держит один ключ в секрете на
сервере — инструкция в [`server/README.md`](server/README.md). После деплоя
задайте переменную окружения `VITE_AI_BACKEND_URL` (repo variable в GitHub
Actions, см. `.github/workflows/deploy-pages.yml`) — приложение автоматически
переключится с BYOK на бэкенд.

**Gemini** — второй провайдер на выбор в Настройках. У Google пока нет
серверного прокси, поэтому Gemini всегда работает по собственному ключу
пользователя (бесплатный ключ на [aistudio.google.com/apikey](https://aistudio.google.com/apikey)),
даже если Claude уже подключён через бэкенд.

## Установка на телефон

1. Откройте адрес приложения в браузере телефона.
2. **Android (Chrome):** меню (⋮) → «Добавить на главный экран».
   **iPhone (Safari):** кнопка «Поделиться» → «На экран «Домой»».
3. Приложение появится как обычная иконка и будет открываться в полноэкранном режиме.

Весь прогресс хранится локально в браузере устройства (localStorage) — сервер и
регистрация не нужны.

## Разработка

```bash
npm install
npm run dev       # локальный сервер разработки
npm run build     # продакшн-сборка (dist/)
npm run preview   # предпросмотр собранной версии
npm run lint      # проверка кода линтером
```

Стек: React 19 + TypeScript + Vite, Tailwind CSS v4, `vite-plugin-pwa` (офлайн-кэш и
манифест для установки на телефон), `@anthropic-ai/sdk` (лениво подгружается только
для экрана AI-собеседника).
